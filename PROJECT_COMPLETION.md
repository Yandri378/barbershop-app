## 🚀 How to Use

### Instant Setup (Recommended)
```bash
cd barbershop-app
bash setup.sh
```

### Quick Manual Setup
```bash
# 1. Copy .env
cp .env.example .env

# 2. Install dependencies
composer install
npm install

# 3. Setup key
php artisan key:generate

# 4. Run migrations
php artisan migrate:fresh --seed

# 5. Build assets
npm run build

# 6. Start server
php artisan serve
```

### Access Application
- URL: `http://localhost:8000`
- Admin: `admin@barbershop.com` / `password123`
- Customer: `john@example.com` / `password123`
